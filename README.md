# sales-demand-prediction-linear-regression
End-to-end sales and demand prediction project using Linear Regression with Scikit-learn, including data preprocessing, feature engineering, pipeline construction, and business insights.
Businesses rely on accurate sales forecasts to optimize inventory, marketing budgets, and operational planning.

This project develops a Linear Regression model using Scikit-learn to predict future sales based on business and customer-related features. The workflow demonstrates an end-to-end machine learning pipeline from data preprocessing to model evaluation.
